# P0 验证记录

日期：2026-10-28。环境：Windows，Node.js 24.16.0、pnpm 12.8.1。下列结果来自实际命令，不等同于云端生产验收。

## 已通过

- `pnpm typecheck`：前后端 TypeScript 检查通过。
- `pnpm build`：React/Vite 生产构建、后端 TypeScript 编译通过。前端主 JS 约 402KB，gzip 约 127KB。
- `pnpm test`：22 个后端测试全部通过，使用实际 SQLite、临时对象文件及 AWS SDK。
- `pnpm test:e2e`：2 个 Chromium 端到端测试全部通过，测试服务器使用独立数据目录。
- `pnpm test:scale`：100000 条图片记录，候选首次构建约 32–33ms，1000 次缓存命中合计约 0.44ms，测试进程 RSS 约 286–292MB。查询计划使用 image_candidates 覆盖索引，无全表随机排序。该数据是开发机观察值，不是 VPS SLA。

后端用例覆盖：一次性安装、会话与 CSRF、跨源拒绝、密码修改撤销会话、密钥摘要、范围与子目录、密钥过期撤销、私有祖先继承、图片自身私有保留、移动与循环防护、304 前判权、实际图片字节和缩略图、公开查询过滤、签名变体隔离、随机服务来源与标签、三种随机响应、公开管理员预览不返回私有图、服务停用撤销私有链接、限流计数、文件超限与超像素、真实 HTTP 上传中断、存储故障、数据库提交失败清理、重启恢复、缺失对象、回收站恢复及实际对象删除、配置加密、禁用存储仍可读取、备份恢复及 OpenAPI 输入说明。

S3 测试启动本机 HTTP 协议夹具，通过真实 AWS SDK 签名请求验证连接、原图上传、读取字节、缩略图、故障响应和彻底删除。夹具仅存在于测试中，正式应用使用真实 S3 适配器，没有模拟业务接口。

浏览器用例覆盖：安装、登录、创建文件夹、真实文件上传与进度结果、异步缩略图就绪、创建公开随机图服务、访客首页及图库、预览、转私有后旧直链被拒、回收站恢复、多资源范围密钥及仅一次完整显示、站点名称即时更新、深色主题。390px 移动端检查无横向溢出；桌面、移动和深色截图已生成并人工查看。

安装来源校验回归：实际同源的 localhost:9521、127.0.0.1:9521 和开发代理地址均允许；PUBLIC_URL 与实际访问地址不同的浏览器安装流程通过。未信任的转发头、陌生来源、不同端口跨源、null/非规范来源均拒绝；显式代理信任和跨域白名单按配置生效，管理 CSRF 校验保留。

Windows WebP 文件锁回归：生成大于64KB的 WebP 原图，真实执行上传、缩略图生成、读取解码及临时目录清理，验证任务成功且临时文件全部释放。Sharp/libvips 操作缓存已关闭，避免保留内存映射文件；临时文件清理失败独立重试，不覆盖已成功的缩略图状态。

调用上限回归：服务和 API Key 均可保存 rateLimit=0 并连续调用超过默认上限；正数仍限流，切换回0立即生效，负数和小数拒绝。浏览器验证两个输入均可填0、保存及服务配置回显0。

首页改版验证：桌面1280px三列、平板768px两列、手机390px单列，移动端无横向溢出；真实请求验证点击图片刷新且不打开新窗口、API地址复制、横幅公开缩略图异步就绪、无公开资源时的默认背景。类型检查、生产构建及2个浏览器流程重新通过。

## 未验证与限制

- 当前环境没有 Docker 命令，未实际构建或启动 Docker/Compose；相关文件已提供。
- 未使用实际云账号验证 AWS S3、R2、MinIO 等具体供应商；须在目标服务验证私有 Bucket、凭证权限和兼容参数。
- 未在实际 2 核/2GB VPS 上进行并发、带宽、持续运行或内存峰值压测；规模测试只验证候选查询与本机内存观察。
- 缺少用户首页参考图，界面为按已批准原则设计的原创实现。
- 当前仅支持单实例部署；不提供 AI、续传、可配置转换及存储迁移。

本地文件测试在正常 Windows 文件权限下运行，因为工具沙箱临时目录拒绝原子 rename；没有因此改变正式应用的原子文件写入方式。测试结束停止了隔离服务，没有创建正式管理员或生产数据。
