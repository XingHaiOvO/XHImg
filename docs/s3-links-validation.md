## 验证范围

- AWS SDK生成GET预签名地址；独立HTTP夹具使用SigV4规范重新计算签名并校验有效期。验证实际字节、中文和特殊字符、类型、文件名、附件下载及 `private, no-store`。追加查询参数会签名失败，到期后拒绝读取。
- 管理员、公开查询、私有读取、祖先私有、仅上传密钥、密钥过期/撤销、会话到期和站内签名剩余有效期。验证权限变更拒绝新签发，但已经签发的S3地址仍可能有效，符合明确的能力链接语义。
- 未就绪缩略图、发布隔离、回收站不签发；停用存储保留已有读取；缺失对象与存储故障保持404/503分类，签发失败不将正常对象标为丢失。上传提交后签发失败保留201成功与逻辑地址。
- 列表生成地址不逐个HEAD或GET对象；签名等待后重新检查权限和位置。随机JSON及跳转直达S3，image模式仍返回实际字节及正确计数。原有S3重处理与本地/S3迁移回归改为跟随302验证字节。
- 浏览器真实添加隔离S3连接并重新加载CSP，上传图片并直接加载原图/缩略图；访客图库可读取，复制临时/站内地址、过期元数据回退、403后仅一次逻辑回退、双重失败停止自动重试及人工重试均覆盖。浅色手机与深色截图位于 `test-results/s3-preview-mobile.png`、`s3-gallery-dark.png`。
- Path Style通过真实HTTP下载验证；虚拟主机方式验证SDK解析后的签名URL及精确CSP源，未对虚拟域名执行DNS/HTTPS下载。

原有本地图片、权限、上传续传、AI夹具、随机图、存储迁移、回收站及后台交互流程同时回归。共享类型和OpenAPI包含逻辑地址与到期字段；未增加数据库迁移。
