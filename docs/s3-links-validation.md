## 协议与权限覆盖

- AWS SDK 生成 GET 预签名地址；独立 HTTP 夹具使用 SigV4 规范重新计算签名并校验有效期。验证实际字节、中文和特殊字符、类型、文件名、附件下载及 `private, no-store`。追加查询参数会签名失败，到期后拒绝读取。
- 管理员、公开查询、私有读取、祖先私有、仅上传密钥、密钥过期/撤销、会话到期和站内签名剩余有效期。验证权限变更拒绝新签发，但已经签发的 S3 地址仍可能有效，符合明确的能力链接语义。
- 未就绪缩略图、发布隔离、回收站不签发；停用存储保留已有读取；缺失对象与存储故障保持 404/503 分类，签发失败不将正常对象标为丢失。上传提交后签发失败保留 201 成功与逻辑地址。
- 列表生成地址不逐个 HEAD 或 GET 对象；签名等待后重新检查权限和位置。随机 JSON 及跳转直达 S3，image 模式仍返回实际字节及正确计数。原有 S3 重处理与本地/S3 迁移回归改为跟随 302 验证字节。

## 浏览器与地址回退

- 浏览器真实添加隔离 S3 连接并重新加载 CSP，上传图片并直接加载原图/缩略图；访客图库可读取，复制临时/站内地址、过期元数据回退、403 后仅一次逻辑回退、双重失败停止自动重试及人工重试均覆盖。浅色手机与深色截图位于 `test-results/s3-preview-mobile.png`、`s3-gallery-dark.png`。
- Path Style 通过真实 HTTP 下载验证；虚拟主机方式验证 SDK 解析后的签名 URL 及精确 CSP 源，未对虚拟域名执行 DNS/HTTPS 下载。
