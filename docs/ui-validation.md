## 验证对象

- 手机导航使用带遮罩的 Radix 抽屉；支持 Escape、点击遮罩和关闭按钮，锁定背景滚动、约束焦点，关闭后返回触发按钮，切换页面或扩大到桌面时关闭。
- 弹窗采用固定标题和独立滚动内容区，适配手机可视高度；提交时阻止重复请求和意外关闭，失败保留输入并显示表单错误。危险操作确认默认聚焦取消，说明实际对象及后果。迁移源副本继续使用独立确认步骤。
- 成功提示自动消失，错误提示保留到手动关闭；后续成功不覆盖未关闭的错误。提示均提供键盘可访问的关闭按钮。
- 数据查询区分首次加载与后台刷新；刷新不替换已有列表，失败保留上次成功内容并提供重试。请求取消、序号和查询路径共同防止旧响应覆盖新结果；同一钩子的重复刷新合并为一个请求。
- 整理和迁移任务只在页面可见且存在活动任务时串行轮询；页面重新可见时刷新一次。上传和手动整理页面不额外轮询隐藏的分类列表，上传本身的状态与续传机制保持。
- 设置标签使用 `storage`、`migrations`、`keys`、`processing`、`ai`、`site`、`security`；整理标签使用现有状态名以及 `upload`、`manual`、`all`。刷新和前进后退保留标签，未知值回到默认标签，切换设置标签清除无关的 `task` 参数。活动标签在切换和窗口缩窄后自动进入可见范围。
- 手机文件夹树可折叠；切换文件夹或筛选会清除选择，同一查询刷新保留仍有效的选择。批量工具栏可换行，表格在手机端采用既有明细卡片或局部滚动，长名称及错误信息可换行。
