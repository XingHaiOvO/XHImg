# P2 存储迁移验证

日期：2026-10-29。Windows、Node.js 24.16.0、pnpm 12.8.1。只使用隔离数据库、临时对象和本机协议夹具；未对正式图库执行迁移或清理，未修改真实服务凭证。

## 自动化验证

- 完整后端51个用例、5条浏览器流程通过；前后端类型检查、生产构建及格式检查通过。迁移页面按需加载，主JS约492KB（gzip153KB），迁移页面独立约11.6KB。

- 迁移核心用例覆盖：本地与S3往返、不同本地配置、共享Bucket的两套S3配置；原图、当前结果和缩略图一起切换，旧签名可继续读取实际字节，权限和版本保持。
- 一致性用例覆盖：同大小错误内容、事务切换失败、磁盘不足暂停、源副本活跃读取、目标缺失禁止清理、彻底删除全部迁移副本、重复预览和任务占用、草稿过期、回收站及子文件夹范围。
- 额外验证截断来源不会切换、复制和源删除故障可重试、历史引用最终释放、临时目录回收不删除非服务目录；迁移I/O等待期间仍可执行其他图片上传和缩略图任务。
- SQLite一致性备份与对象目录复制恢复到独立数据目录后，当前结果、保留原图和迁移源副本均可读取；恢复不会自动删除源副本，明确cleanup后才清理。
- 真实SDK中断用例在PUT已接收但未响应时暂停，验证请求中断、迁移锁释放；模拟重启恢复后复核已有目标字节，未重复上传或累计成功数。SDK可能输出预期的流式请求中断提示，任务结果验证通过。
- AI视觉接口使用本机夹具，在模型等待期间完成物理迁移，再提交逻辑归档；文件夹、私有权限及目标存储均正确。
- 浏览器验证设置中心添加迁移目标、资源列表勾选、冻结预览、确认执行、旧直链读取、明确确认源副本清理、空筛选不可执行，以及390px手机布局。截图在 `test-results/storage-migration-*.png`。

## 规模与资源观察

`pnpm test:migration-scale`：100000张元数据记录。冻结预览约1883ms，确认入队约1601ms，1000次队列头查询约10.6ms，RSS约296MiB。队列计划使用migration_items_task(task_id,state)索引，无临时排序；无状态明细分页使用migration_items_pages。报告为 `.cache/p2-scale.json`。

`pnpm test:resources`：100MiB源PNG经过P1处理后，迁移其原图、当前JPG和缩略图三个对象。本地到本地，包含预览、流式暂存、SHA-256回读校验和切换，耗时约0.44秒，CPU时间约0.72秒，采样峰值RSS约346MiB（迁移开始基线约313MiB）。源副本仍保留。报告为 `.cache/p2-resources.json`。这是开发机观察，不是生产性能承诺。
