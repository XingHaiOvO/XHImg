## 阅读约定

- API 参考中的短路径以 `/api/v1` 为前缀；图片传输 `/i/{id}`、`/t/{id}` 和健康检查 `/health` 位于站点根路径。
- 文件大小使用 MiB、GiB，时间戳字段除特别说明外使用 Unix 毫秒。
- 文档中的 ID、域名和密钥均需替换为自己的值。多行 shell 示例使用 POSIX 语法；PowerShell 调用 curl 时使用 `curl.exe`，并将参数写在同一行或改用 PowerShell 续行语法。
- 部署仅支持单实例。Docker、真实云服务商和持续负载等验证限制见[验证记录](validation.md)。
